采购常见问题（FAQ）

起订量与 FOB 阶梯价、下单前如何核验我们、不同市场要哪些认证、打样与大货交期、OEM 与 ODM 的区别与定制项——全部依据站内已公开的数据回答。

起订量与价格

起订量（MOQ）是多少？

现货型号可 1 pcs 起；OEM 通常 200 pcs 起；ODM 项目在规格确定后按型号单独报价。

FOB 价格怎么算？

按数量阶梯定价。以扫地机器人为例：200–499 pcs 为 US$165/pc，500–999 pcs 为 US$130/pc，1000 pcs 起为 US$95/pc；无线吸尘器与蒸汽清洁机同理。

一个订单可以混装多个型号吗？

可以。经销商混装很常见，阶梯价按每个型号各自的数量计算。

供应商核验与质检

下单前怎么核验你们？

本店检测报告与符合性声明都有编号可查：EFW526022843-CG-02+REV 1、CTA25030700203 / CTA25030700205 / CQASZ20250902238E / YHJC202412100039R1、XDX50238736101701EC，有效期至 2031-07-24 与 2031-09-07。公司为香港大麥家科技有限公司，成立于 2024 年，团队 51–100 人，国际站店铺 2025-11-16 开店（评分 4.81/5、回复率 99.87%）。

质量怎么控制？

按六步流程执行：询盘与需求确认 → 打样与确认 → 定制方案确认 → 批量生产 → QC 验货 → 出货与单证。可安排你指定的第三方验货。

认证与合规

你们持有哪些认证？

扫地机器人与无线吸尘器：CE / FCC / RoHS / CB；蒸汽清洁机：CE / CB / ETL。完整证书编号与有效期见「出口认证与合规」页。

进口到欧盟或美国需要哪些认证？

这类产品的常见组合是：欧盟 CE（LVD / EMC / RoHS）+ REACH + WEEE；美国 FCC（含无线模块）+ UL 或 ETL（电气安全）。具体清单请与你的进口商确认，详见认证页的市场对照表。

证书有效期多久？

上述两组证书分别有效期至 2031-07-24 与 2031-09-07。

打样与交期

可以先打样吗？

可以，样品数量 5 pcs，打样周期 7–14 天。

大货生产要多久？

定制方案确认后 25–35 天，视数量与包装而定。

OEM / ODM 与定制

OEM 和 ODM 的区别？

OEM 是基于现有型号使用你的品牌与包装；ODM 是在我方平台上调整外观或功能，形成你的独占型号。

可以定制哪些？

Logo（丝印 / 镭雕 / 贴标）、按 Pantone 打色的配色，以及包装（彩盒 / 瓦楞盒 / 礼盒）。

下单、出口与单证

怎么下单？

六步：询盘与需求确认 → 打样与确认 → 定制方案确认 → 批量生产 → QC 验货 → 出货与单证。

主要出口哪些地区？

北美、南美、东欧、东南亚（来自国际站店铺后台数据）。
